### 変更理由 (Reason for change)

clinical_v3 では validation set = test set であり、early stopping のモデル選択にテストデータが使用されていた（楽観的バイアスの可能性）。clinical_v3_retrain では2-Phase Training により train-val-test を完全分離し、方法論的に堅牢な評価を実現した。

### 主要な知見

1. **Multiclass改善**: Zone (+7.1pp Acc), Stage (+3.8pp QWK), Plus (+2.0pp QWK) が大幅改善
2. **Binary低下**: Treatment Sens 89.0→70.7%, AUC 0.975→0.922 (val=testバイアス除去後の真の値)
3. **A-ROP video-level 100%**: 全条件(All/Top-10/Top-5)で sensitivity 100% を達成
4. **閾値最適化の有効性**: Video-level Top-5 + Youden で Treatment Sens 97.0% / Spec 93.0%
5. **RW-ROP**: Per-image 87.2%/87.8%, Video-level (Youden) 95.2%/87.1%

### 計算方法の注意点

- majority_vote_results.json の RW-ROP sensitivity/specificity は、soft-voted multiclass予測からのhard derivation（argmax後にOR結合）で計算
- Table 6 の閾値最適化は probability-based threshold（video-averaged task probs → RW-ROP prob → threshold）
- このため Table 4 と Table 6 の RW-ROP default値が異なる（84.5% vs 94.1%）
