### 執筆内容

#### Materials and Methods (セクション 2.1–2.7)

| サブセクション | 内容 |
|---------------|------|
| 2.1 Study Design | Multicenter retrospective study（IRBプレースホルダー） |
| 2.2 Datasets | 22症例ベスト画像データ + 5施設347動画多施設データ + 画質分類 |
| 2.3 Image Processing | RT-DETR-L (lens, 640×640) + RF-DETR-Nano (fundus seg, 448×448) |
| 2.4 Best Image Selection | 品質特徴量5種 + 22症例版(rank_sum) + 多施設版(edge_cov filter+score) |
| 2.5 Classification Model | EfficientNet-B0 + ClinicalEncoder MLP → 1312次元 → 5タスクヘッド |
| 2.6 Video Aggregation | Soft/Hard voting × All/Top-10/Top-5 |
| 2.7 Evaluation | 5-fold StratifiedGroupKFold, メトリクス定義 |

#### Results (セクション 3.1–3.5)

| サブセクション | 主要結果 |
|---------------|---------|
| 3.1 Dataset | クラス分布（6,448画像） |
| 3.2 Best Image | Image concordance 54.5%, Video concordance 86.4% |
| 3.3 Per-Image | Zone Acc 73.2%, Treatment AUC 0.975, RW-ROP AUC 0.956 |
| 3.4 Video-Level | Treatment Sens 100% (Top-10/Top-5 soft), AROP Sens 100% (Top-5 soft) |
| 3.5 Threshold | Treatment Youden: Sens 96.3%/Spec 93.3% |
