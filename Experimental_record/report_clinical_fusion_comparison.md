# ROP分類モデルにおける臨床特徴量融合とPlus Disease追加の効果検証レポート

**作成日**: 2026-02-03（初版）、2026-02-06（v3追加・Plus影響分析を統合）
**データセット**: Multicenter ROP Study（6,448画像、Good + Fair）
**モデル基盤**: EfficientNet-B0 + Multi-task Learning
**交差検証**: StratifiedGroupKFold 5-fold（患者単位グループ化）

---

## 1. 背景と目的

ROP（未熟児網膜症）の重症度分類において、眼底画像のみによるAIモデル（class_balanced_v1）をベースラインとし、以下の2つの問いを検証した:

1. **臨床データの追加効果**: 性別・在胎週数・出生体重・月経後週数の追加が分類性能を向上させるか
2. **Plus Disease追加の影響**: マルチタスク学習にPlus分類（Normal / PrePlus / Plus）を追加した場合、他タスク（特にAggressive ROP）に悪影響を与えるか

計4つのモデルバリアントを構築し、系統的に比較した。

### 2.5 クラス不均衡への対策

本データセットは特にAggressive ROP（陽性3.5%）、Plus（PrePlus+Plus 16.3%）、Treatment（陽性9.7%）に極端なクラス不均衡が存在する。以下の多層的な対策を全4モデル共通で適用した。

#### (1) Weighted Cross-Entropy Loss

クラス頻度の逆数に基づく重みを損失関数に適用。少数クラスの誤分類に対してより大きなペナルティを与える。

重み計算式: weight_i = total / (n_classes x count_i)、最小値で正規化

| タスク | クラス別重み |
|--------|------------|
| Zone | I: 5.29 / II: 1.00 / III: 2.29 |
| Stage | 0: 1.00 / 1: 1.81 / 2: 2.26 / 3: 3.34 |
| Plus | Normal: 1.00 / PrePlus: 8.42 / Plus: 13.18 |
| Aggressive ROP | No: 1.00 / Yes: 27.28 |
| Treatment | No: 1.00 / Yes: 9.28 |

重みは各foldの学習データから再計算し、データリークを防止している。

#### (2) Weighted Focal Loss

通常のCross-Entropyに加え、Focal Loss (gamma=2.0) を併用。容易に分類できるサンプルの損失を抑制し、分類困難なサンプル（境界例や少数クラス）に学習を集中させる。

最終損失 = (Weighted CE + Weighted Focal Loss) / 2

#### (3) タスク重み付け

| タスク | タスク重み |
|--------|----------|
| Zone / Stage / Plus | 1.0 |
| Aggressive ROP | 1.5 |
| Treatment | 1.5 |

#### (4) Label Smoothing

Label smoothing (epsilon=0.1) を適用。過度な確信度を抑制し、少数クラスへの汎化性能を向上させる。

#### (5) MixUp Data Augmentation

MixUp (alpha=0.2, 適用確率50%) により、異なるクラスのサンプルを線形補間した仮想サンプルを生成。臨床特徴量も同一のlambdaパラメータで補間。

#### (6) Stratified Cross-Validation

StratifiedGroupKFold により、各foldのクラス分布を元データと同等に維持。患者単位のグループ化でリーク防止と公正な評価を両立。

## 4. 結果: Plus Disease追加の影響（v1 vs v3）

v1とv3はアーキテクチャが同一（全タスクにfused特徴量を入力）で、唯一の違いはPlus taskの有無である。

### 4.1 全タスク比較

| タスク | 指標 | v1 (Plus無) | v3 (Plus有) | 差分 |
|--------|------|-------------|-------------|------|
| AROP | AUC | 0.947 +/- 0.064 | 0.888 +/- 0.131 | -0.059 |
| AROP | Sensitivity | 0.920 +/- 0.089 | 0.832 +/- 0.242 | -0.088 |
| AROP | Kappa | 0.289 +/- 0.164 | 0.278 +/- 0.185 | -0.011 |
| Treatment | AUC | 0.974 +/- 0.017 | 0.975 +/- 0.025 | +0.001 |
| Treatment | Sensitivity | 0.857 +/- 0.129 | 0.890 +/- 0.109 | +0.033 |
| Treatment | Kappa | 0.721 +/- 0.141 | 0.739 +/- 0.145 | +0.018 |
| Zone | Kappa | 0.692 +/- 0.018 | 0.669 +/- 0.024 | -0.023 |
| Stage | Kappa | 0.784 +/- 0.041 | 0.776 +/- 0.023 | -0.008 |

### 4.2 主要な所見

**AROPのみ顕著に悪化**: AUCが0.947から0.888に低下（-0.059）、Sensitivityが0.920から0.832に低下（-0.088）。標準偏差も0.064から0.131に増大し、fold間の不安定性が悪化。

**Treatmentはむしろ微改善**: AUCは0.974→0.975と同等、Sensitivityは0.857→0.890と+0.033改善。

**Zone/Stageへの影響は軽微**: Kappa低下はZone -0.023、Stage -0.008で、臨床データ追加による改善幅（+0.07〜0.11）に比べ十分小さい。

### 4.3 AROPが悪化する原因の考察

1. **タスク間干渉**: Plus DiseaseはAROPの構成要素であり臨床的に強く相関する。共有backboneの特徴量がPlus分類にも使われることで、AROP特有の微細な特徴の学習が阻害される。

2. **クラス不均衡の増幅**: AROP陽性は228例（3.5%）と極めて少ない。Plus（PrePlus+Plus = 1,047例、16.3%）の方がサンプル数が圧倒的に多く、学習時のloss勾配がPlus側に引き寄せられやすい。

3. **fold間の不安定性**: v3のAROP AUCの標準偏差は0.131と全モデル中最大。少数のAROP陽性症例が特定のfoldに偏ることで結果が大きく変動。

## 7. 結論

1. **臨床データはZone/Stageに有効**: 在胎週数・出生体重・月経後週数はZone/Stageの重症度と臨床的に強い相関があり、Kappa +0.07〜0.11の改善が確認された。

2. **Plus追加はAROPに悪影響**: 同一アーキテクチャでPlus有無のみを変えた比較（v1 vs v3）で、AROP AUCが0.947から0.888に低下（-0.059）。Plus DiseaseとAROPの臨床的関連性が高く、共有backbone上でタスク間干渉が発生。

3. **TreatmentはPlus追加と臨床データの恩恵**: v3のTreatment AUC 0.975、Sensitivity 0.890は全モデル中最良。治療判断には臨床情報（GA, BW等）が有用であることが示唆される。

4. **選択的融合（v2）はAROPへの悪影響を軽減**: Plus追加が必要な場合、v2（AROP/Treatmentから臨床データを除外）がAROPのAUC 0.936を維持し、v3の0.888より良好。

5. **clinical_v1が総合的に最良**: Plus不要の場合、全タスクに臨床データを使用するv1がZone/Stage/AROPで最高性能を示し、バランスが最も良い。

## 8. 推奨構成と今後の方針

### 推奨構成

- **Plus分類が不要な場合**: clinical_v1（全タスク臨床融合、Plus無し）を採用
- **Plus分類が必要な場合**: clinical_v2（選択的融合）を採用し、AROPへの干渉を最小化

### 今後の検討事項

- AROP/Treatmentの改善にはデータ拡充（陽性症例数の増加）が最も効果的
- Plus Disease分類を独立モデルとして分離し、マルチタスク干渉を完全回避
- 2段階推論（backbone凍結 → ヘッド別学習）によるAROPへの影響緩和
- AROP headのtask_weightを増加させ、Plusとの勾配競合を緩和する実験
- 臨床データのみによる予測（画像なし）をベースラインとして追加し、画像の寄与度を定量化
