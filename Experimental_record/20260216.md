## Train+Val Retrain Notebook 作成 (clinical_v3_retrain)

### 概要 (Overview)
TVT (train 60% / val 20% / test 20%) の結果で Treatment Sensitivity が 5-fold CV (97%) から大幅に低下 (82%) した問題に対応するため、2-Phase Training 手法を実装した新しい notebook を作成した。

### 新規作成ファイル (New file)
`Article/train_clinical_v3_retrain.ipynb`

### ベースファイル

### Before / After 比較

| 項目 | clinical_v3_tvt (Before) | clinical_v3_retrain (After) |
|------|--------------------------|------------------------------|
| VERSION | `clinical_v3_tvt` | `clinical_v3_retrain` |
| OUTPUT_DIR | `outputs_clinical_v3_tvt` | `outputs_clinical_v3_retrain` |
| Stratify target | `zone + stage` | `zone + stage + treatment` |
| Training | Phase1のみ (60%学習、20% early stop、20%評価) | Phase1 (best epoch特定) + Phase2 (80%でN epoch再学習) |
| 最終モデル | `best_model.pt` | `retrained_model.pt` |
| skip logic | `best_model.pt` の存在確認 | `retrained_model.pt` の存在確認 |
| Phase2 clinical stats | N/A | train+val (4/5) から再計算 |
| Phase2 class weights | N/A | train+val (4/5) から再計算 |
| Phase2 モデル初期化 | N/A | ゼロから再初期化 (Phase1の重みを引き継がない) |
| Phase2 scheduler | N/A | OneCycleLR(epochs=best_epoch) |
| Cell 11 比較対象 | clinical_v3 のみ | clinical_v3 + clinical_v3_tvt 両方 |

### 変更理由 (Reason for change)

1. **学習データ量の問題**: TVTでは学習データが60%に減少し、特にTreatment (少数クラス) のSensitivityが97%→82%に大幅低下
2. **解決策**: Phase 1でval foldを使いbest epoch Nを決定後、Phase 2でtrain+val (80%) でN epoch固定で再学習。これにより学習データ量を80%に戻しつつ、test setの独立性を保つ
3. **Stratify改善**: treatment_labelを追加することでfold間のtreatment分布を均等化

### 実装の詳細

#### Cell 5 の主要変更点:
- `compute_class_weights_from_df()` ヘルパー関数の追加（Phase1/Phase2で異なるデータから計算するため）
- Phase 1: 従来のtrain/val分割で学習 → best_epoch を記録
- Phase 2: train+val結合 → fresh model → N epoch固定学習 → retrained_model.pt保存
- Phase 2では `set_seed(42)` でモデル初期化の再現性を確保
- `drop_last=True` は元のTVTと同一（BatchNorm対策）

#### Cell 6 の変更点:
- `cv_method` 文字列を更新

#### Cell 11 の変更点:
- clinical_v3、clinical_v3_tvt、clinical_v3_retrain の3方式比較表

### 考察

#### 改善した点
1. **Multiclass タスク (Zone/Stage/Plus)** は3方式中最高 — 2-Phase retrainのデータ量増加が効果的
   - Zone Accuracy: v3 0.73 → retrain **0.80** (+7pp)
   - Stage Kappa: v3 0.78 → retrain **0.81** (+4pp)
   - Plus Kappa: v3 0.75 → retrain **0.77** (+2pp)
2. **Video-Level (Soft Vote Top-10)** でも全multiclassタスクが改善
   - Zone Kappa: tvt 0.57 → retrain **0.70** (+13pp)
   - RW-ROP F1: tvt 0.77 → retrain **0.82** (+5pp)

#### 悪化した点
1. **Treatment Sensitivity** がさらに低下: v3 0.89 → tvt 0.83 → retrain **0.71** (-18pp vs v3)
   - SDが0.18と大きく、fold間のばらつきが大きい
   - 2-Phase retrainは少数クラスの改善には寄与しなかった
2. **AROP Sensitivity** も低下: v3 0.83 → retrain 0.75 (-8pp)
   - SDが0.38と非常に大きい（fold 4で特に悪化の可能性）

#### 根本的な問題
- Treatment/AROPは少数クラス（Treatment positive ~10%、AROP ~3.5%）であり、train-val-test分割でtrain比率が下がるとsensitivity低下が顕著
- 2-Phase retrainで80%に戻しても、v3の80%→100%（=val fold含む）に比べてevaluation leakageがない分、見かけ上の数値は下がる
- **v3 (val=test) のTreatment Sensitivity 0.89は楽観的バイアスを含んでいた可能性が高い**
- Video-level soft vote Top-10では Treatment Sensitivity 0.82 を維持しており、集約による改善効果がある

#### 結論
- **論文にはclinical_v3_retrainの結果を使用すべき** — 方法論的に最も堅牢
- Per-image Treatment Sensitivity低下 (0.71) は、video-level集約で0.82に回復
- Multiclassタスクは一貫して改善されており、2-Phase retrainの有効性を示す

## Treatment Sensitivity ≥ 95% 閾値分析

### 解析目的 (Purpose)
スクリーニング用途ではSensitivity ≥ 95%が必須要件であるため、Treatment / RW-ROPの閾値をSensitivity ≥ 95%に設定したときのSpecificity、PPV、NPV、F1を全条件（Per-Image / Video-Level Soft Vote × All / Top-10 / Top-5）について比較した。

### 解析手法 (Methods)
- 対象データ: v3_tvt および v3_retrain の predictions.csv
- ROC曲線から TPR ≥ 0.95 かつ FPR 最小の閾値を選出
- 6条件: Per-Image (All / Top-10 / Top-5), Soft-Vote (All / Top-10 / Top-5)
- 品質特徴量は `selected_images_disc_retina.xlsx` からマージ、Top-10/Top-5はC-rule3_thr0.80で選出
