## 血管セグメンテーション: データ準備 + 学習パイプライン構築

### 概要 (Overview)

`E:\Kaisho_vascular_annotation\Human_Annotation` の22枚の眼底画像＋血管アノテーションマスクを用いて、
血管セグメンテーションのための学習パイプラインを構築した。
lens検出→クロップ→リサイズのデータ準備、Frangiベースライン、U-Net学習の3つのノートブックを作成。

### 新規作成ファイル

| ファイル | 内容 |
|---------|------|
| `ROP_project/vascular_segmentation/prepare_data.ipynb` | データ準備（lens検出、クロップ、マスクアライメント、QC可視化） |
| `ROP_project/vascular_segmentation/frangi_baseline.ipynb` | Frangiフィルタベースライン（閾値最適化付き） |
| `ROP_project/vascular_segmentation/train_unet.ipynb` | U-Net学習（smp, ResNet34, 4-fold CV） |

### データ特徴

| 項目 | 値 |
|------|------|
| 画像数 | 22枚 |
| 画像形式 | JPEG encoded .png, 1080×1920 or 1920×1080 |
| マスク形式 | RGBA PNG, 2160×3840（画像の2倍解像度） |
| マスク色 | Red(R=255,G=0,B=0)=血管, White(255,255,255)=背景 |
| Alpha | 全ピクセル255（透過なし） |
| 血管ピクセル比率 | ~1% (sample: 1.014%) |

### パイプライン設計

**prepare_data.ipynb:**
1. RT-DETR (`rtdetr-l-1697_1703.pt`) でlens領域検出
2. `infer_case_video.py` の `pick_best_lens_bbox`, `clamp_xyxy`, `apply_circular_mask_to_crop` を再利用
3. マスクは2倍スケールのbboxでクロップ → `INTER_NEAREST` でリサイズ
4. `(G==0) & (B==0)` でバイナリ化 → circle_maskとAND
5. 全画像512×512に統一 → `data/{images,masks,circle_masks}/` に保存

**frangi_baseline.ipynb:**
- Green channel + CLAHE + 反転 → `skimage.filters.frangi(sigmas=1..11)`
- 閾値グリッドサーチ → 最適閾値でメトリクス計算
- 期待Dice ~0.25

**train_unet.ipynb:**
- `segmentation_models_pytorch` U-Net (ResNet34 encoder, ImageNet pretrained)
- 学習: 4-fold KFold, 200 epochs, batch=16, Adam lr=1e-4, cosine annealing
- 拡張: RandomCrop(256), Flip, Rotate, ElasticTransform, BrightnessContrast等
- 損失: BCE(pos_weight=10) + Dice (0.5 + 0.5)
- circle_mask内のみで損失・メトリクス計算
- 評価: Dice, IoU, Sensitivity, Specificity, Precision

### 変更理由 (Reason for change)

Frangiフィルタのベースライン実測がDice 0.254と不十分であり、アノテーション（主要血管のみ）との意味的ミスマッチが根本原因。
DRIVEデータセットの先例（20枚でDice > 0.80）から、U-Netがこの少量データでも大幅改善を達成できると判断。

### 実行手順

1. `prepare_data.ipynb` → data/ 生成＋QC確認
2. `frangi_baseline.ipynb` → ベースライン数値確認
3. `train_unet.ipynb` → 4-fold CV学習＋比較

## 実験結果

### Frangiベースライン改善試行

| 手法 | Dice | Precision | Sensitivity |
|------|------|-----------|-------------|
| Green Frangi (erosion前) | 0.262 | 0.193 | 0.432 |
| Green Frangi (erosion 10px) | 0.325 | 0.295 | 0.383 |
| Frangi × Sat × (R-G) | 0.346 | 0.332 | 0.386 |

- Circle mask erosion (10px) でレンズ縁FPを除去 → Dice +0.063
- 色重み付け（彩度、R-G差分、HSV Hue等 8手法テスト）→ 最大+0.021の微小改善
- 根本原因: 血管と背景の色分布が重なる（網膜自体が赤橙色）ため色フィルタの限界

### U-Net 4-fold CV 結果

| Metric | Frangi (best) | U-Net | 改善 |
|--------|--------------|-------|------|
| **Dice** | 0.337 | **0.621** | **+0.284** |
| IoU | 0.218 | 0.461 | +0.243 |
| Sensitivity | 0.398 | 0.790 | +0.392 |
| Precision | 0.314 | 0.518 | +0.204 |
| Specificity | 0.946 | 0.956 | +0.010 |

- U-Net (ResNet34, ImageNet pretrained) が22枚データでFrangiの**1.84倍のDice**を達成
- 22枚中21枚で Dice > 0.45、中央値 ≈ 0.68
- 外れ値: 30A0F797 (Dice=0.185) — vessel_pct=0.70%（最小、アノテーション極めてスパース）
- Sensitivity 0.790: アノテーション主要血管の約8割を検出

### 考察

- Frangiは全リッジ構造を検出 → 主要血管のみのアノテーションとの意味的ミスマッチが根本問題
- U-Netはアノテーションパターンを直接学習できるため、この問題を本質的に解決
- DRIVEデータセット(20枚, Dice>0.80)と比較すると0.62はやや低いが、
  アノテーションがスパース（主要血管のみ）であることを考慮すると妥当

### Inference Pipeline

ソース画像は `selected_images_disc_retina` のフル画像（crop前）のため、
RT-DETR lens検出 + 円形マスク処理を含む。

```
1. cv2.imread(full_image) → img_bgr (H×W×3)
2. RT-DETR lens検出 → bbox (xyxy)
3. crop = img_bgr[y1:y2, x1:x2]
4. apply_circular_mask_to_crop(crop) → masked_crop, circle_mask
5. cv2.resize(masked_crop, (512,512)) → img_512
6. ImageNet normalize + U-Net ensemble(4 folds) → sigmoid average → threshold 0.5
7. pred_512 × circle_mask_512 → 円形外除外
8. binary → RGBA PNG (Red=血管, White=背景)
```

## 血管セグメンテーションプロジェクト: 全体概要

### 目的 (Purpose)

ROP眼底画像における血管セグメンテーションモデルを構築する。
最終的にmulticenter studyの全症例に対して血管マスクを自動生成し、
臨床研究（血管走行の定量評価等）に活用することを目指す。

### プロジェクト構成

```
ROP_project/vascular_segmentation/
```

### HITL (Human-In-The-Loop) 反復学習計画

本プロジェクトの精度向上戦略は以下のHITL反復サイクルに基づく：

```
┌─────────────────────────────────────────────────┐
│  Round N                                         │
│                                                  │
│  1. U-Net inference                              │
│     → Before_HITL/{images,masks}/ に予測マスク出力 │
│                                                  │
│  2. 改正先生が予測マスクを修正                      │
│     → 修正済みマスクを回収                         │
│                                                  │
│  3. 修正マスクを学習データに追加                    │
│     → data/{images,masks}/ を拡張                 │
│                                                  │
│  4. U-Net再学習 (train_unet.ipynb)               │
│     → Dice改善を確認                              │
│                                                  │
│  5. 改善したモデルで次バッチをinference            │
│     → Round N+1 へ                               │
└─────────────────────────────────────────────────┘
```

**Round 0 (現在):**
- 学習データ: 22枚 (Human_Annotation)
- U-Net Dice: 0.621
- 3,089枚のBefore_HITLマスクを生成済み → 改正先生に修正依頼中

**Round 1 (予定):**
- 改正先生の修正済みマスクを回収
- 修正マスクを学習データに追加（22枚 → 数十〜数百枚に拡張）
- U-Net再学習 → Dice改善確認
- 残りの画像に対してinference → 次ラウンドのBefore_HITLへ

**収束判定:**
- Dice > 0.80 を目標（DRIVE等の先例相当）
- 改正先生の修正量が十分小さくなった時点で終了
