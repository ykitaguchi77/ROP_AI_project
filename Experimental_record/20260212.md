# 2026-02-12 実験記録

## Image Quality Classifier (EfficientNet-B0) 初回学習

### 概要 (Overview)
久保田先生によるGood/Fair/Bad/Worstの4段階画質分類ラベル（9,962枚、394症例、5施設）を用いて、
EfficientNet-B0ベースのDeep Learning画質分類モデルを構築・5-fold CVで評価した。

### 新規作成ファイル (Created files)
```
ROP_project/image-quality-classifier/
├── config.py        # 設定 (パス, ハイパーパラメータ)
├── dataset.py       # Dataset, transforms, case-level 5-fold split
├── model.py         # EfficientNet-B0ラッパー (timm)
├── train.py         # 学習スクリプト
├── evaluate.py      # 評価スクリプト
└── checkpoints/     # モデル重み, ログ, confusion matrix画像
```

### データ
- 9,962枚 (Good:4494, Fair:1997, Bad:2879, Worst:592)
- 394症例, 5施設 (AMU:70, FU:103, KCMC:53, OWCH:120, YCH:48)
- 画像: レンズcrop済み 525x630 PNG → 224x224リサイズ
- 43枚の0バイト破損ファイル発見 → `selected_lens_images_disc_retina`から復元

### モデル・学習設定
- EfficientNet-B0 (ImageNet pretrained, timm) → 全層fine-tune
- 症例単位5-fold CV (StratifiedGroupKFold, 施設層化)
- Weighted CrossEntropyLoss (inverse frequency)
- AdamW (lr=1e-4, weight_decay=1e-4), CosineAnnealingLR
- Early stopping (patience=7, monitor=val_loss)
- Data Augmentation: RandomResizedCrop, HFlip, VFlip, ColorJitter, Rotation

### 解釈・考察 (Interpretation)
- GoodとBad/Worstの分類は比較的良好（F1 0.64-0.79）
- **Fairが最も困難**（F1=0.42）— Good/Badとの境界が曖昧、主観的判断が大きい
- ±1段階以内の正解率95.2%は臨床的に実用レベル（大外れは少ない）
- 施設間差: KCMC(55%)が最も低い → 画質傾向が他施設と異なる可能性
- Early stoppingがEpoch 3-4で発動 → 過学習が早い。lr低下やregularization強化を検討
- 全foldでtrain_acc 85%超 vs val_acc 64-68% → 過学習傾向あり
