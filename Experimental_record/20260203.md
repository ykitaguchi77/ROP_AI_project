# 2026-02-03 実験記録

## Confusion Matrix 可視化の追加

### 概要 (Overview)

`train_rop_classifier_class_balanced.ipynb` および `train_rop_classifier_clinicalData.ipynb` に、4タスク（Zone / Stage / Aggressive ROP / Treatment）の Confusion Matrix ヒートマップ表示セルを追加。

### 変更元ファイル (Source file)

- `ROP_project/multicenter_study/train_rop_classifier_class_balanced.ipynb`
- `ROP_project/multicenter_study/train_rop_classifier_clinicalData.ipynb`

### Before / After 比較

| 項目 | Before | After |
|------|--------|-------|
| Confusion Matrix 表示 | テーブル（Sensitivity/PPV）のみ | テーブル + ヒートマップ（2x2サブプロット） |
| 正規化 | なし | 行正規化（各真クラスごとの割合） |
| アノテーション | なし | 件数 + 割合（%）を併記 |
| 画像保存 | なし | `{OUTPUT_DIR}/confusion_matrices.png` に保存 |

### 変更理由 (Reason for change)

- 各クラス間の誤分類パターンを直感的に把握するため
- テーブルのみでは多クラス（Zone 3クラス、Stage 4クラス）の混同傾向が見えにくい

## 選択的臨床特徴量融合 (Selective Clinical Fusion) の実装

### 概要 (Overview)

clinical_v1（全タスクに臨床情報を投入）の結果分析から、臨床特徴量はZone/Stageには有効だがAggressive ROP/Treatmentには悪影響であることが判明。タスクごとに臨床情報の使用を選択するアーキテクチャ（clinical_v2）に変更。

### 変更元ファイル (Source file)

`ROP_project/multicenter_study/train_rop_classifier_clinicalData.ipynb`

### clinical_v1 の結果（変更の根拠）

| Task | Metric | Image-Only | Clinical v1 (全融合) | Diff |
|------|--------|-----------|---------------------|------|
| Zone | Kappa | 0.5638 | **0.6920** | +0.128 |
| Stage | Kappa | 0.6401 | **0.7835** | +0.143 |
| AROP | Accuracy | **0.9208** | 0.7697 (±0.31) | -0.151 |
| AROP | AUC | **0.9702** | 0.9472 | -0.023 |
| Treatment | AUC | 0.9548 | 0.9742 | +0.019 |

→ Zone/Stage は大幅改善、AROP は大幅悪化、Treatment はほぼ横ばい

### Before / After 比較

| 項目 | Before (clinical_v1) | After (clinical_v2) |
|------|---------------------|---------------------|
| アーキテクチャ | 全タスクに Fused (1312-dim) | Zone/Stage/Plus → Fused (1312-dim)、AROP/Treatment → Image Only (1280-dim) |
| CLINICAL_TASKS | なし（全ヘッドが同一入力） | `{'zone', 'stage', 'plus'}` を定義 |
| forward() | 全ヘッドに fused を入力 | タスクごとに fused / img_feat を振り分け |
| MultiTaskHead 入力次元 | 全て 1312 | Zone/Stage/Plus: 1312、AROP/Treatment: 1280 |
| VERSION | clinical_v1 | clinical_v2 |
| OUTPUT_DIR | outputs_clinical/ | outputs_clinical_v2/ |

### 変更理由 (Reason for change)

- clinical_v1 の実験結果から、臨床特徴量（GA, BW, PMA, Sex）はZone/Stageの重症度分類には強い付加価値があるが、Aggressive ROP（228例、3.5%）のような極少数クラスではノイズとして作用し精度を悪化させることが判明
- タスクごとに最適な入力を選択するSelective Fusionにより、各タスクの長所を活かす設計
- 既存の outputs_clinical/ は保持し、outputs_clinical_v2/ に新規出力することで比較可能性を維持
