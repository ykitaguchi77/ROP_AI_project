## Technical Notes

### Environment

- GPU: CUDA enabled
- Framework: PyTorch + timm
- Base Model: EfficientNet (pretrained on ImageNet)

### Data Split Strategy

- 5-Fold Group K-Fold
- Stratify by: `treatment_label`
- Group by: `video_id` (同一動画からの画像は同じfoldに)

### Multi-Task Architecture

```
EfficientNet-B0 (backbone)
    |
    └── Global Average Pooling
            |
            ├── Zone Head (3 classes)
            ├── Stage Head (4 classes)
            ├── Plus Head
            ├── Aggressive ROP Head (2 classes)
            └── Treatment Head (2 classes)
```

### Loss Function

- Multi-Task Loss with task weights
- Label Smoothing Cross-Entropy
- Task weights: zone=1.0, stage=1.0, aggressive_rop=1.5, treatment=1.5

## コード変更: process_multicenter_videos_score80.ipynb 作成

### 変更元ファイル
`ROP_project/multicenter_study/process_multicenter_videos.ipynb`

### 新規作成ファイル
`ROP_project/multicenter_study/process_multicenter_videos_score80.ipynb`

---

### Before / After 比較

| 項目 | Before (process_multicenter_videos.ipynb) | After (process_multicenter_videos_score80.ipynb) |
|------|-------------------------------------------|--------------------------------------------------|
| フレーム抽出間隔 | 5フレーム毎 (`FRAME_INTERVAL = 5`) | 毎フレーム (`FRAME_INTERVAL = 1`) |
| all_images保存 | `E:\...\all_images` に保存 | **保存しない**（一時ディレクトリ使用） |
| all_lens_images保存 | `E:\...\all_lens_images` に保存 | **保存しない**（一時ディレクトリ使用） |
| 選別基準 | disc_edge_coverage >= 0.80 + retina_ratio >= 30 の2段階選出 | **score >= 0.8** のみ |
| 最大選出数 | TOP_K = 30（最大30枚） | 制限なし（score >= 0.8を満たす全画像） |
| Excel出力先 | `selected_images.xlsx` | `selected_images_score80.xlsx` |

---

### スコア計算式（両バージョン共通）

```
score = 0.4 × retina_ratio_norm + 0.4 × mbss_Grad_p90_norm + 0.2 × mbss_score_norm
```

各指標はMin-Max正規化（0-1）後に重み付け。

---

### 処理フロー変更

**Before**:
1. 動画から5フレーム毎に抽出 → `all_images` に保存
2. 品質評価 → `all_lens_images` に保存
3. disc_edge_coverage + retina_ratio で2段階選出（最大30枚）
4. `selected_images` / `selected_lens_images` にコピー

**After**:
1. 動画から毎フレーム抽出 → **一時ディレクトリ**に保存
2. 品質評価 → **一時ディレクトリ**にlens_image保存
3. score >= 0.8 の画像を選出（枚数制限なし）
4. `selected_images` / `selected_lens_images` にコピー
5. **一時ディレクトリは自動削除**（容量節約）

---

### 変更理由
- 毎フレーム抽出により、より多くの高品質画像を取得可能
- all_images/all_lens_imagesの保存を廃止することで、ストレージ容量を大幅に削減
- score >= 0.8 という明確な閾値で品質の高い画像のみを選出

### 評価指標の定義

#### 画像一致率（Image Match Rate）

**定義**: AIが選んだTop5画像のうち、Humanが選んだ画像と一致する枚数の割合

```
画像一致率 = Σ(各動画でAI Top5とHuman選定が一致する枚数) / (動画数 × 5)
```

#### 動画一致率（Video Match Rate）

**定義**: 22動画のうち、**少なくとも1枚以上**AIとHumanの選定が一致する動画の割合

```
動画一致率 = (1枚以上一致した動画数) / 総動画数
```

| 指標 | 何を測定するか | 特徴 |
|------|---------------|------|
| **画像一致率** | 選定の「精度」 | 厳しい評価。5枚全て一致して初めて100% |
| **動画一致率** | 選定の「網羅性」 | 緩い評価。1枚でも当たれば成功とカウント |

---

### 特徴量一覧

#### 1) Retina / Lens 基本量

- **`lens_area`**: lens円形マスク内の画素数
- **`retina_area`**: セグのRetinaマスク画素数（lens内に限定）
- **`retina_ratio`**: retina_area / lens_area × 100

#### 2) Disc位置

- **`disc_center_dist_ratio`**: Disc中心からLens中心までの距離 / Lens半径
- **`disc_pos_ok`**: `0.25 <= disc_center_dist_ratio <= 0.75` のとき True

#### 3) 画質（MBSS）

- **`mbss_L_multi`**: マルチスケールLaplacian分散（シャープネス寄り）
- **`mbss_HF_ratio`**: FFT高周波エネルギー比（ディテール寄り）
- **`mbss_Spec_centroid`**: FFTスペクトル重心（周波数分布）
- **`mbss_Grad_p90`**: 勾配強度の90パーセンタイル（エッジ寄り）
- **`mbss_score`**: 上記4つを case_id 内で z-score 正規化し重み付き和

#### 4) Disc Edge Coverage（辺縁被覆率）

- **`disc_edge_coverage_ratio`**: Discの辺縁がRetinaマスクに覆われている割合
- **`disc_edge_covered`**: coverage >= 0.95 のとき True

#### 5) 色調

- **`S_mean`**: HSVのS=彩度の平均（網膜マスク内のみ）

---

### 開発フェーズ

#### Phase 1: 初期アプローチ（ランクベース）

**スコア計算式**:
```
rank_sum = 1.5 × retina_area_rank + 1.0 × mbss_rank + 0.5 × disc_ring_rank + 0.5 × s_mean_rank
```

**結果**:
- 画像一致率: ~48/110 (43.6%)
- 動画一致率: ~18/22 (81.8%)

#### Phase 2: Random Forest による最適化試行

**手法**:
```python
features = ['retina_ratio', 'mbss_score', 'mbss_Grad_p90', 'disc_ring_score', 'S_mean']
# Human選定画像 = 1, それ以外 = 0
rf = RandomForestClassifier(n_estimators=100, random_state=42)
```

**結果**:
- Feature Importance から `retina_ratio` と `mbss_Grad_p90` が重要と判明
- 大幅な精度向上には至らず（約50%程度で頭打ち）
- **結論**: 既存の指標だけではHumanの選定基準を十分に捉えられていない

#### Phase 3: 問題動画の詳細分析

**Video 1632（0/5一致）の分析**:
- AI選定画像: Discが画像の端にあり、辺縁がRetinaマスクからはみ出し
- Human選定画像: Discが画像中央寄りにあり、辺縁が完全にRetinaで覆われている

```
AI選定画像:
  retina_ratio:    86.1%  (高い)
  disc_edge_cov:   0.952  (やや低い)
  disc_center_dist: 0.675 (端寄り)

Human選定画像:
  retina_ratio:    79.3%  (やや低い)
  disc_edge_cov:   0.981  (高い)
  disc_center_dist: 0.503 (中央寄り)
```

**→ disc_edge_coverage_ratio 指標の発見**

#### Phase 4: Disc Edge Coverage 閾値の最適化

| 閾値 | 画像一致数 | 一致率 | 動画一致率 |
|------|-----------|--------|-----------|
| 0.75 | 58/110 | 52.7% | 19/22 (86.4%) |
| **0.80** | **60/110** | **54.5%** | **19/22 (86.4%)** |
| 0.85 | 58/110 | 52.7% | 18/22 (81.8%) |
| 0.90 | 55/110 | 50.0% | 18/22 (81.8%) |
| 0.95 | 48/110 | 43.6% | 17/22 (77.3%) |

**結論**: 閾値 **0.80** が最適

### 最終アルゴリズム（validate_images_disc.ipynb / process_multicenter_videos.ipynb）

#### 足切り条件

1. `retina_ratio >= 30`（絶対足切り）
2. `disc_edge_coverage_ratio >= 0.80`（Stage 1優先条件）

#### スコア計算式（Stage 1）

```
score = 0.4 × retina_ratio_norm + 0.4 × mbss_Grad_p90_norm + 0.2 × mbss_score_norm
```

#### 選定ロジック

1. **Stage 1**: disc_edge_coverage >= 0.80 AND retina_ratio >= 30 → スコアでソート
2. **Stage 2**: disc_edge_coverage < 0.80 だけど retina_ratio >= 30 → retina_ratioでソートして補完
