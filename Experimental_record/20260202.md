## train_rop_classifier_clinical.ipynb の新規作成

### 概要 (Overview)

`train_rop_classifier_class_balanced.ipynb` をベースに、臨床データ（性別、GA、BW、PMA）を画像特徴量と結合して分類するノートブックを新規作成。Concatenation Fusionアーキテクチャを採用。

### 新規作成ファイル (New file)

`ROP_project/multicenter_study/train_rop_classifier_clinical.ipynb`

### Before / After 比較

| 項目 | Before (class_balanced) | After (clinical) |
|------|------------------------|-------------------|
| 入力 | 画像のみ | 画像 + 臨床特徴量 (4次元) |
| モデル | ROPMultiTaskModel (EfficientNet-B0 → 1280次元 → 分類ヘッド) | ROPClinicalMultiTaskModel (1280 + ClinicalEncoder 32次元 = 1312次元 → 分類ヘッド) |
| ClinicalEncoder | なし | MLP: 4→64→ReLU→BN→Dropout→32→ReLU→BN |
| 臨床特徴量 | なし | Sex (binary), GA (z-score), BW (z-score), PMA (z-score) |
| 正規化 | なし | 各foldの学習データからmean/std計算（リーク防止） |
| 欠損値処理 | なし | 連続値→中央値補完、性別→0.5 |
| MixUp | 画像のみ | 画像 + 臨床特徴量の両方を同一lambdaで補間 |
| チェックポイント | model.state_dict()のみ | model_state_dict + clinical_mean/std/median |
| 出力先 | outputs_class_balanced/ | outputs_clinical/ |
| Dataset | ROPDataset | ROPClinicalDataset (clinical tensor返却) |
| 予測CSV | 画像パス + 予測結果 | 画像パス + 予測結果 + 臨床特徴量 |
| 比較ベースライン | good_fair (画像のみ、重み無し) | class_balanced_v1 (画像のみ、クラス重み付き) |

### 変更理由 (Reason for change)

- 臨床データ（在胎週数、出生体重など）はROP重症度と強い相関があり、画像のみのモデルに付加価値を与える可能性がある
- Late fusion (concatenation) は医学画像研究で最も一般的で、画像のみとの比較（ablation study）が明確
- per-fold正規化により情報リークを防止し、学術論文レベルの実験設計を確保
